# VK → Discord

Личная Windows-утилита для публикации новых глав One Piece из альбомов
сообщества VK 334424 в один выбранный Discord-канал с веткой для каждой главы.

## Состояние на 28 ноября 2026

Рабочая установленная программа — v9 с интерфейсом, треем и обновлением
оформления карточки. Пользователь подтвердил успешную повторную публикацию
главы 1200 после обновления `vk_card_update_v2`.

**Актуальная установленная v9 пока не импортирована в этот репозиторий.**
Доступный основной исходный снимок `vk_discord_publisher/` — v7. Он сохранён
для истории и тестов; его нельзя выдавать за текущую рабочую версию или
устанавливать поверх v9. Для первого коммита подготовлены именно доступные
материалы, а не воспроизводимая сборка текущего приложения.

## Текущая задача

Одобрены простая смена единственного сервера/канала и ручной выбор ожидаемой
главы. Несколько одновременных направлений публикации не нужны. Прежде чем
менять интерфейс, необходимо импортировать текущие исходники v9 и сверить их
с установленной версией.

Изменения основного поведения, адаптивное наблюдение 5/10 минут и дальнейшие
этапы подготовки к продакшну не включены в настройку Git.

## Репозиторий и установка

Git хранит исходники, тесты и документы. Токены, конфигурация, скачанные главы,
история публикаций и журналы остаются вне репозитория. Архивы и вспомогательные
файлы переноса также не отслеживаются. `.gitignore` использует список разрешённых
папок; для добавления новой папки исходников его нужно явно обновить.

Этот репозиторий пока локальный, без удалённого адреса. GitHub или другой
сервер Git можно подключить отдельно. Локальные коммиты сами по себе не являются
резервной копией на другом устройстве.

Первого коммита пока нет: запись `.git/index.lock` запрещена правами среды
помощника. Запрос дополнительного доступа автоматически отклонён политикой,
отключающей повышение разрешений. `git init` выполнен, правила исключений
подготовлены и проверены, но файлы ещё не добавлены в индекс. Для продолжения
локальной работы Git среде нужна запись в `.git` этого проекта.

Порядок дальнейшей работы описан в [DEVELOPMENT.md](DEVELOPMENT.md).
