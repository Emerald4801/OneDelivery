Это не означает, что все изображения уже скачаны или что расписание установлено.
Значение ключа пользователь не передавал, оно не включено в архив обновления.

## Выполненные уточнения v7

1. Полный обход API-списка при обычной получасовой проверке. Для порядка 800
   альбомов и порции 100 — около восьми запросов. Не полагаемся на позицию главы
   в первой порции. Пятиминутное наблюдение остаётся адресным.
2. После полного обхода кеш кандидатов заменяется свежим списком: удалённый
   старый пустой альбом не мешает обработке новой заполненной версии.
3. Источник выбирается явно через vk_mode=api. Один сохранённый ключ не меняет
   веб-режим. Ошибка API не вызывает скрытый переход на HTML.
4. Проверка API сохраняет ключ и отчёт, но сама не меняет режим источника.
5. Установщик перед регистрацией задачи выбирает API по успешному сохранённому
   отчёту. Повторный ввод ключа не нужен. Проверяются источник, альбом, успешность,
   порядок, наличие изображения и сохранённого ключа; настройки чужого источника
   не переключаются по этому отчёту.
6. Перед включением задачи остаётся диагностика VK и Discord без публикации.
   Она показывает режим источника, последнюю полную главу в Discord и следующий
   ожидаемый номер. Только после её успеха задача регистрируется и запускается.

## Границы текущей проверки

Общий локальный прогон: 83 теста, 81 успешно, 2 пропущены из-за недоступности
DPAPI в среде выполнения. Синтаксис PowerShell проверяется отдельно при упаковке.

Из ограниченной среды выполнения доступ к config.json в LOCALAPPDATA запрещён.
Секреты не читались, обход этого ограничения не предпринимался. Поэтому полную
диагностику и регистрацию Планировщика из этой среды не выполняли. Код, тесты
и упаковка обновления выполняются в рабочей папке проекта, существующая
установка в Downloads и действующая рабочая папка не перезаписаны.

Следующий шаг пользователя: распаковать v7 и запустить INSTALL_AUTO.cmd.
Он использует уже сохранённый ключ и отчёт в %LOCALAPPDATA%\VKDiscordPublisher,
переносит прежние настройки Discord при необходимости, проверяет доступы и
после успеха включает задачу. При ошибке сохранить текст результата для разбора.

## Что остаётся прежним

Discord задаёт последний опубликованный номер, ищем строго следующий. В VK
пустые альбомы-дубликаты отбрасываются, неоднозначные заполненные версии не
выбираются наугад. Готовность — четыре наблюдения за 15 минут без изменения
состава/порядка; это эвристика. После скачивания состав проверяется повторно.
Карточка: ГЛАВА N, Страниц: число, ссылка на ветку. В ветке — пачки изображений
под спойлерами в порядке источника. Ручной контроль порядка каждую неделю не нужен.
