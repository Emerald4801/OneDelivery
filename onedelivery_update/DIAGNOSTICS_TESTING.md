Контрольная метка — tested-diagnostics-2026-11-28.

## Поведение

- Окно показывает идентификатор сборки и дату по Москве. Установщик также
  сообщает сборку и путь резервной копии. Git в установленной программе не нужен.
- Версия подтверждается хешами установленных файлов. Неизвестная сборка,
  повреждённые метаданные и изменённый код различаются. Сборка из изменённых
  вне коммита исходников обозначается явно.
- Метаданные updates/installed_build.json заменяются и откатываются вместе
  с кодом; первая установка такой версии при откате удаляет новый файл.
  Повторная установка того же пакета сохраняет прежнюю дату установки.
- Окно «Диагностика…» собирает локальное состояние в фоне. Проверяются доступ
  к рабочим файлам, версия Python/зависимостей, свежесть обработчика, совпадение
  сборок окна/обработчика, ручная пауза, срок повтора, глава и подтверждённые страницы.
- Две задачи Windows читаются отдельным скриптом. Проверяется соответствие
  действия текущей папке. Задачи не запускаются и не изменяются диагностикой.
- Только кнопка «Проверить связь» обращается к Discord и VK. Discord проверяет
  подключение и основные права через GET; VK читает первую страницу альбомов
  API либо web-источника. Результат не запускает публикацию, восстановление
  карточки или наблюдение готовности.
- «Сохранить отчёт» создаёт JSON в diagnostics установленной программы.
  Отчёт содержит только выбранные поля. Исходные журналы, config, токены,
  подписанные URL, названия каналов и XML задач не прикладываются. Текст ошибки
  преобразуется в категорию; тела сетевых исключений не экспортируются.

## Последующая ручная проверка сна и выключения

Эти действия пока не выполнялись. После установки достаточно коротких проверок:

1. Сон во время ожидания повтора. После пробуждения уже прошедший срок не
   отсчитывается заново; при восстановлении связи попытка становится доступна.
2. Сон во время отправки. Возможен разрыв соединения и потерянный ответ;
   после пробуждения история сверяется, подтверждённые группы не дублируются.
3. Выключение при частичной отправке, затем включение и вход в Windows.
   Обработчик поднимается через свою задачу, использует прежнюю ветку и квитанцию.
4. Ручная пауза и выбранная глава сохраняются после запуска; второй обработчик
   и второй значок не создаются.

Для примера 6/16 требуется сверить фактические сообщения после восстановления:
Discord мог принять следующую группу до потери ответа. Восстановление должно
учесть её, даже если локальный счётчик ещё показывал шесть страниц.

72 календарных часа уже проверены автоматическими сценариями с перезапуском
и большим скачком времени. Держать компьютер выключенным трое суток или менять
часы Windows для ручной проверки не требуется. Во время сна/выключения локальное
приложение не публикует; просроченная работа возобновляется после запуска и с
учётом расписания поиска новых глав. Реальная проверка сети, входа в Windows
и восстановления остаётся отдельным пользовательским действием.
