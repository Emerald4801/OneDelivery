OneDelivery — смена единственного назначения и ожидаемой главы

Запуск из папки проекта: UPDATE_ONEDELIVERY.cmd.
Архив OneDelivery_settings_update.zip содержит тот же узкий пакет для переноса.
Не запускайте старые INSTALL_AUTO / UPDATE_STAGE1 / UPDATE_STAGE2 для этой доработки.

Обновление не меняет config.json, токены, историю, расписание, пользовательский
значок или паузу автоматики. Новые зависимости не устанавливаются.
Сначала сверяются хеши установленной v9 и всех файлов пакета. Неожиданный код
приводит к отмене. Затем установщик ждёт до 30 секунд освобождения блокировки
отправки и удерживает её до конца обновления. Только после этого останавливается
конкретная проверенная задача этого приложения; активная отправка не прерывается.
Если обработчик занят, обновление отменяется без принудительного завершения.
Окно и трей закрываются штатным сигналом и открываются после замены файлов.
Прежние Enabled/Disabled и Running/Ready задачи восстанавливаются.
При ошибке замены возвращаются все исходные файлы. Каталог резервной копии
показывается в результате: %LOCALAPPDATA%\VKDiscordPublisher\updates\settings_...

Для возврата к прежнему коду после успешной установки:
UPDATE_ONEDELIVERY.cmd --restore "ПОЛНЫЙ_ПУТЬ_К_РЕЗЕРВНОЙ_КОПИИ"
Возврат кода не отменяет последующую смену канала и не удаляет публикации.

В окне появятся:
— «Выбрать главу…»: номер сохраняется до подтверждённой публикации этой главы;
  отсутствие альбома и ошибки его не сбрасывают. Полная существующая глава
  повторно не отправляется. Такая цель остаётся выбранной до смены или сброса.
— «Вернуть автоматический выбор»: снова расчёт по полным публикациям Discord.
— «Сменить сервер / канал…»: список серверов бота и текстовых каналов. Доступ
  проверяется только чтением; сообщения при проверке не отправляются.

Смена канала ждёт штатного завершения обработчика, меняет обе задачи Windows,
сохраняет историю каждого канала отдельно и оставляет автоматику на паузе.
Чтобы начать работу в новом канале, нажмите «Проверить сейчас» либо
«Возобновить автоматику». Эти команды могут приводить к реальной публикации.
В пустом канале можно указать первую ожидаемую главу. Если поле пустое, начальная
точка — последняя готовая глава VK, ожидается следующая; архив не отправляется.
При незавершённой публикации или ручной проверке смена назначения отменяется.
При ошибке переключения прежние config, задачи и команды нового канала
восстанавливаются. Резервная копия: updates\destination_... установленной программы.

Наблюдение по-прежнему 10 минут (0, 5, 10); автоматический поиск 12:00–24:00 МСК
каждые 30 минут, 72 часа паузы после автоматической публикации. Ручная проверка
доступна на паузе и не вводит новую паузу на 72 часа.

Сборка из исходников: python onedelivery_update\build_package.py
