Скачивание альбома ВК на Windows
==============================

По умолчанию: https://vk.ru/album-334424_310875314

БЫСТРЫЙ ЗАПУСК
1. Полностью распакуйте ZIP в отдельную папку, например Downloads\VKAlbum.
2. Нужен Python 3.10 или новее: https://www.python.org/downloads/windows/
   При установке включите Python Launcher или Add Python to PATH.
3. Запустите start.cmd двойным щелчком.
   Первый запуск скачает gallery-dl, requests и Pillow из PyPI в локальную .venv.
   Установка может занять несколько минут. Нужен доступ к PyPI.
4. Изображения и CBZ появятся в downloads\album-334424_310875314.

Скрипт работает через ваше подключение. Российский IP сам по себе не является
подтверждённым обязательным условием: важен фактический доступ к ВК и его CDN.
Установка зависимостей и извлечение альбома тоже требуют интернета.

ЕСЛИ ВК ТРЕБУЕТ ВОЙТИ
Сначала проверьте, что альбом открывается в вашем браузере после входа в ВК.
Скрипт не запрашивает пароль или API-токен.

Вариант A: из PowerShell в папке программы:
  .\.venv\Scripts\python.exe download_album.py --browser firefox
  или --browser chrome / --browser edge
Это явное разрешение программе прочитать cookies выбранного браузера локально.
gallery-dl может читать хранилище cookies браузера целиком для поиска нужных;
не используйте этот вариант, если не хотите предоставлять такой доступ.
Современная защита cookies Chrome/Edge в Windows может не позволить их прочитать;
этот способ не гарантирован. Пароли браузера программа не запрашивает.

Вариант B: Netscape cookies.txt только для ВК.
Экспортируйте cookies ВК локально способом, которому доверяете, и положите файл
cookies.txt рядом со start.cmd. Он автоматически будет использован при запуске.
Cookies для vk.com и vk.ru могут различаться: используйте домен, на котором вошли,
и при необходимости передайте ссылку vk.com вместо vk.ru.
Cookies дают доступ к сессии. Не отправляйте их другим людям или в чат.
Скрипт не экспортирует cookies и не добавляет их в CBZ, журнал или manifest.json.
Не устанавливайте случайные расширения только ради экспорта cookies.

ДРУГИЕ АЛЬБОМЫ И ПРОВЕРКА КОЛИЧЕСТВА
PowerShell, из папки программы после первого запуска:
  .\.venv\Scripts\python.exe download_album.py "https://vk.ru/album-334424_310875314" --expected 12
При несовпадении с ожидаемым числом уникальных фотографий скачивание не начнётся.
Число 12 взято со скриншота: используйте его только если оно совпадает со счётчиком
этого конкретного альбома. Скрипт сам не проверяет счётчик веб-страницы.
Другую папку можно задать через --output "D:\Manga".

ПОРЯДОК, КАЧЕСТВО, ПРОВЕРКИ
- Извлечение фотографий выполняет gallery-dl. Скрипт получает готовые URL от него,
  а не сохраняет миниатюры сетки альбома. Он не выбирает разрешение независимо
  от gallery-dl: максимальный размер и качество этого альбома пока не проверены.
- Имена 0001.jpg, 0002.jpg и т.д. сохраняют порядок выдачи gallery-dl.
  Этот порядок не является независимой проверкой правильного порядка чтения!
  Откройте первые несколько страниц и проверьте последовательность и развороты.
- Файлы проверяются Pillow. HTML-страница ошибки не сохраняется как JPG.
- В manifest.json сохраняются ID фотографий, размеры и SHA-256. Cookies и прямые
  временные ссылки туда не записываются. ID — идентификаторы, не номер страницы.
- Повторный запуск заново получает список, проверяет контрольные суммы и пропускает
  целые скачанные файлы. Незавершённое изображение скачивается с начала.
- Если состав или порядок альбома изменился, скрипт остановится. Задайте новую
  папку --output для новой копии, чтобы не смешивать разные версии альбома.
- CBZ создаётся только после успешного скачивания всех найденных изображений.
  При ошибке старый CBZ от прошлого успешного запуска может оставаться в папке.
- Максимальная версия в ВК не обязательно совпадает с исходным архивом на Turbobit:
  для оценки потерь качества требуется сравнение соответствующих изображений.

ОБНОВЛЕНИЕ И ОШИБКИ
Если ВК изменил сайт, обновите gallery-dl из PowerShell:
  .\.venv\Scripts\python.exe -m pip install --upgrade gallery-dl requests Pillow
После этого повторите запуск. При капче решите её вручную в браузере; скрипт не
умеет автоматически решать капчи. При ограничениях запросов остановитесь и
повторите позже. Удалённые/недоступные фотографии не восстанавливаются.
Если gallery-dl сообщает ошибку авторизации даже с актуальной сессией, может
потребоваться другой механизм извлечения. Скрипт не гарантирует поддержку любых
изменений ВК. На живом альбоме работа в этой сессии не была проверена.

СВЕДЕНИЯ
Исходник полностью открыт: download_album.py и start.cmd.
Не читает форум, Turbobit, личные сообщения и не публикует ничего в ВК.
Скачивает выбранный альбом; список альбомов сообщества автоматически не собирает.
