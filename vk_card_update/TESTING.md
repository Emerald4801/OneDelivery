# Проверки изменения карточки

Изменяются только формат и режим отправки карточки, а также завершение её статуса при восстановлении прерванной публикации. Паузы, источник VK, очереди и интервалы наблюдения сохраняются.

Проверено на Windows / Python 3.10:

- 10 проверок новой логики: порядок «загрузка → страницы → опубликовано», короткое упоминание ветки, флаги обычной/тихой отправки, спойлеры и порядок 16 страниц, продолжение после потерянного ответа, восстановление финального статуса без повторных POST, сохранность старых завершённых карточек, идемпотентность обновления и откат двух файлов при ошибке.
- 65 регрессионных проверок предоставленного рабочего проекта с адаптацией ожидаемой строки карточки; одна проверка DPAPI пропущена в изолированном контексте. Проверка Windows mutex прошла.
- Исполнение настоящего PowerShell-установщика в отдельной тестовой папке с реальной заменой файлов. Команды Планировщика и запуск окна имитировались; проверено сохранение четырёх сочетаний «задача включена/отключена, работает/остановлена».
- Нативный синтаксический разбор PowerShell и компиляция Python.

В рабочей папке доступен исходный проект v7. Исходники установленной v9 недоступны агенту для прямого чтения. Поэтому установщик применяет узкое преобразование к существующей v9: проверяет ожидаемую структуру, компилирует результат, сохраняет исходные байты и сверяет хеши перед заменой. При несовпадении структуры замена не начинается. Контракт восстановления подтверждений v9 проверен отдельной явной фикстурой.

Настоящие задачи установленного бота не запускались и не останавливались, сообщения в Discord при разработке не отправлялись. Применение к установленной копии выполняет пользователь запуском `APPLY_CARD_UPDATE.cmd`.
