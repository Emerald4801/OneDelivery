# План: новые главы One Piece из ВК в личный Discord

Дата: 23 ноября 2026 года. Документ описывает разработку; бот и расписание ещё не настроены.

## Цель и исходная точка

На компьютере пользователя работает загрузчик альбома ВК. Пользователь подтвердил скачивание 12 изображений из https://vk.ru/album-334424_310875314 и совпадение порядка с альбомом.

Первая версия должна находить новые альбомы с главами в сообществе 334424, скачивать изображения и публиковать их в выбранном канале личного сервера Discord. Каждой главе соответствует отдельная ветка, каждой фотографии — отдельное сообщение. Сохраняем порядок альбома и развороты. Добавляем каталог опубликованных глав и команды управления.

## Предлагаемые настройки

| Параметр | Начальное решение |
| --- | --- |
| Место запуска | Компьютер пользователя с Windows |
| Источник | Альбомы сообщества ВК 334424; нужную редакцию перевода уточнить по названиям и описаниям |
| Частота проверки | Каждые 30 минут, пока программа запущена; интервал настраивается |
| Готовность альбома | Три успешные проверки за минимум 60 минут без изменений списка и порядка фотографий; эвристика, не гарантия полноты |
| Первая синхронизация | Зафиксировать существующие альбомы; старые главы автоматически не публиковать |
| Формат Discord | Карточка главы, ветка, изображения по одному в последовательных сообщениях |
| Состояние | SQLite для поиска, очереди и публикации; JSON-манифесты для скачанных файлов |
| CBZ | Необязательная локальная копия; для публикации изображений не требуется |

Проверка раз в неделю может пропустить удобный момент выхода. Регулярный поиск новых альбомов учитывает перерывы и переносы без предположения, что новая глава обязательно выходит каждую неделю.

## Этап 1. Импорт одной главы в Discord

- Подключить обычного Discord-бота к выбранному серверу и каналу.
- Сохранить токен локально вне исходников и архива для передачи; не отправлять токен в чат.
- Выдать нужные права просмотра канала, отправки сообщений, вложений, создания веток, отправки внутри веток и чтения истории для восстановления после сбоев. Проверить права на выбранном канале.
- Добавить импорт по известной ссылке, используя уже проверенный загрузчик.
- Сначала полностью скачать главу, проверить изображения и размеры вложений. Исходники автоматически не уменьшать: слишком большой файл останавливает публикацию с понятным сообщением.
- Создать карточку с номером главы, ссылкой на ВК, числом фотографий и статусом «Публикуется». В ветке отправлять файлы строго последовательно с подписями «1/12», «2/12» и т.д.
- После подтверждения всех отправок отметить главу опубликованной и добавить в каталог.

Критерий готовности: выбранная тестовая глава появилась в Discord полностью, в проверенном порядке и без необходимости вручную отправлять картинки.

## Этап 2. Продолжение после ошибок

- Хранить идентификаторы альбома, фотографий, карточки, ветки и сообщений; фиксировать результат каждой подтверждённой отправки.
- При повторном запуске продолжать незавершённую главу, а опубликованную пропускать.
- При неопределённом результате отправки — например, сервер принял файл, но ответ потерялся — сверять историю ветки и стабильные отметки страниц перед повторной отправкой. Сохранения ID только после ответа недостаточно для защиты от этого случая.
- Учитывать ограничения Discord по ответам API, повторять временные ошибки с задержкой. При постоянной ошибке останавливать текущую главу, сохраняя прогресс и порядок.
- Предотвращать одновременный запуск двух экземпляров публикации.
- Изменённую уже опубликованную главу помечать для проверки; автоматическое удаление или перестановку опубликованных сообщений в первой версии не выполнять.

Критерий готовности: перезапуск, обрыв сети, повреждение локального файла и потерянный ответ API не приводят к неконтролируемым повторным публикациям или перемешиванию страниц.

## Этап 3. Обнаружение новых альбомов ВК

- Отдельно проверить получение списка альбомов с компьютера пользователя, включая пагинацию. Работа загрузки одной ссылки ещё не подтверждает работу поиска всех альбомов.
- Выбрать работающий способ: чтение доступных страниц сообщества либо официальный photos.getAlbums при подходящем доступе. При необходимости авторизации использовать локальную сессию; применимость API-токена проверить отдельно.
- Определять главы по проверенным правилам названий и описаний; не считать любой числовой альбом главой без проверки структуры источника.
- Использовать ID альбома как основной ключ; номер главы — для отображения и проверки. Разные альбомы с одинаковым номером требуют выбора нужной версии.
- На первой проверке запомнить уже существующий список, не отправляя весь архив.
- Отслеживать новые подходящие альбомы независимо от их позиции в списке и очередности ID. Не считать ошибку чтения пустым альбомом или отсутствием новых глав.
- Перед публикацией проверять стабильность списка фотографий; после скачивания повторно сверять состав и порядок. Изменение возвращает альбом в ожидание.
- Дать ручной импорт известной ссылки на случай, когда автоматический поиск временно не работает.

Критерий готовности: находится новый подходящий альбом, посторонние альбомы исключаются, существующий архив не публикуется автоматически. Пограничные названия можно проверить на сохранённых тестовых данных без ожидания реального выхода главы.

## Этап 4. Работа по расписанию

- Один процесс бота обслуживает Discord-команды и периодический поиск. Долгое скачивание выполнять в рабочей очереди, не блокируя команды.
- Добавить запуск при входе в Windows через Планировщик заданий и восстановление после сбоя. Исключить повторные экземпляры.
- При запуске после сна или выключения выполнить проверку и продолжить очередь; не проигрывать накопившиеся таймеры подряд.
- Хранить время последней успешной проверки, ближайшей попытки и причину ошибки. Ошибка ВК не должна выглядеть как успешная проверка без новых глав.
- При истёкшей сессии сообщать о необходимости входа. Если Discord тоже недоступен, сохранять локальный журнал и показывать состояние после восстановления связи.
- Для постоянной работы компьютер должен оставаться включённым, программа — запущенной, а ВК и Discord — доступными. Перенос на сервер возможен позднее после проверки доступа к обоим сервисам.

Критерий готовности: после перезагрузки бот возвращается к работе и догоняет пропущенные главы.

## Этап 5. Каталог и управление внутри Discord

| Команда | Назначение |
| --- | --- |
| /check | Запустить проверку источника вручную |
| /import url | Скачать и опубликовать выбранный альбом |
| /latest | Открыть последнюю опубликованную главу |
| /chapter number | Найти главу по номеру |
| /library | Показать каталог со ссылками на ветки |
| /status | Показать состояние поиска, очередь и ошибки |
| /pause и /resume | Приостановить и возобновить автоматическую публикацию |

Управляющие команды ограничить владельцем. Добавить кнопки перехода к ветке, предыдущей и следующей опубликованной главе. Ссылки хранить как ID каналов и сообщений; временные URL вложений не использовать как единственный постоянный адрес изображения.

Критерий готовности: главу можно найти и открыть из Discord; состояние автоматики видно без просмотра консоли.

## Проверка перед обычным использованием

1. Импорт известного альбома: сверить число фотографий, порядок и читаемость.
2. Повторный импорт того же альбома: новая копия не создаётся.
3. Остановка на середине публикации и запуск заново: продолжение с проверкой уже отправленного.
4. Потерянный ответ отправки: сверка истории перед повтором.
5. Добавление фотографии в ожидающий альбом: ожидание готовности начинается заново.
6. Недоступность ВК, Discord, истёкшая сессия, ограничение запросов, слишком большой файл: понятный статус и сохранённый прогресс.
7. Перезапуск Windows и повторная попытка запуска программы: один действующий экземпляр.

## Что понадобится при реализации

- Сервер и целевой канал Discord, их ID.
- Существующий бот либо создание нового приложения Discord; токен вводится только локально.
- Подтверждение нужного источника/версии перевода, если обнаружатся альбомы с одинаковыми номерами глав.
- Выбор тестовой главы для первой публикации и подтверждение, что сначала публикуем только новые главы.
- Локальный доступ к списку альбомов ВК. Его проверка — главный пока не закрытый технический вопрос.

На этапе составления плана токен и доступ к Discord не требуются.

## Возможное развитие

После устойчивой работы публикации и каталога: Discord Activity с собственной библиотекой, масштабированием, режимами чтения и прогрессом. Это отдельный этап с размещением веб-приложения и хранением изображений; схема данных первой версии должна позволять его добавить.
