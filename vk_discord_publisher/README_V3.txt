Обновление v3 — чистые подписи, номер главы из ВК, изображения под спойлерами
===========================================================================

УСТАНОВКА
Закройте программу. Скопируйте файлы из папки vk_discord_publisher в архиве
в существующую рабочую папку программы с заменой файлов.
Сохраните config.json, token.dpapi, state, downloads, cookies.txt и .venv.
Повторный SETUP не требуется. Старые publish_album.py и README можно оставить.
Командные файлы через обновлённый _run.cmd теперь запускают publish_album_v3.py.
Это обновление к вашей работающей версии, не отдельный установщик.

ЗАПУСК
Для уже скачанной главы запустите обычный PUBLISH_LOCAL.cmd и укажите её папку.
Для альбома по ссылке используйте прежний PUBLISH_ALBUM.cmd.
Название главы больше не вводится. Номер определяется по названию альбома ВК.
Если старый манифест ещё не содержит название, программа один раз запросит его
через gallery-dl с вашего компьютера и сохранит в manifest.json.
Для этого первого обращения нужны доступ к ВК и, если потребуется, прежняя
авторизация (cookies.txt или параметр --browser).

В DISCORD
Карточка в основном канале:
  ГЛАВА 1199 (жирным)
  Страниц: 12
  ссылка на ветку

Внутри ветки:
  Страницы 1-6
  шесть изображений под спойлерами

  Страницы 7-12
  шесть изображений под спойлерами

Нет ссылки на ВК, превью ВК, статусов, версии, контрольных сумм, технических меток
или общего количества в подписях пачек. Эти сведения остаются в локальных файлах.
Имя ветки также обновляется до «ГЛАВА 1199». Архивирование — через 7 дней.
Порядок исходных изображений и ограничения размера пачек сохраняются.

РАНЕЕ ОПУБЛИКОВАННЫЕ ГЛАВЫ
Новый формат применяется к новым публикациям. Ранее опубликованные главы
пропускаются: их сообщения, подписи, картинки и обсуждения не меняются.
Утилит для изменения или удаления старых сообщений в обновлении нет.
Если публикация прежней версии была прервана, завершите её прежней программой.
Не удаляйте state: при неоднозначности программа остановится, не создавая дубль.

НОМЕР ГЛАВЫ
Поддерживаются названия вида «1199», «Глава 1199», «1199: название» и «Chapter 1199».
Дробные номера сохраняются. Диапазон или несколько неоднозначных номеров не
угадываются: программа остановится до публикации и попросит проверить название.
Параметр --title из старых команд допускается для совместимости, но игнорируется.

ПРОВЕРКА
Изменения проверены локально на подставных ответах Discord, включая формат
карточек, флаги спойлеров и повторный запуск после потерянного ответа.
В ваш Discord из этой сессии ничего не отправлялось.
